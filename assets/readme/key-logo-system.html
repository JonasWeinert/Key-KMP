Key — identity system

One cap.
Every surface.

The mark is a keycap. Its legend is a block cursor and a caret — the two glyphs a modal editor and a shell already share — set with a hair of space so they resolve into a K.

Every part of the product gets the same cap with a different legend, the way a keyboard gets a different letter on every key.

The set

Press a cap to copy its SVG.

Anatomy

Two flat tones make the depth. No gradient, no bevel, no shadow.

Body
Ink, 96 × 94, r26. Taller lip at the bottom than the top — the cap is read slightly from the front, so it sits rather than floats.
Plate
Paper, inset 10, r16. Radius equals body radius minus inset, so every corner stays concentric.
Cursor
The stem. A block cursor in the accent colour. It is the only coloured element in the whole system.
Caret
The arm and leg. 4.5 units of air between cursor and caret: enough to keep both glyphs legible, tight enough to close into a K.
Legend
Everything lives in a 34-unit optical band. Swap the glyph, keep the band, and any future surface joins the set.

Lockup

The K in the wordmark is the mark itself, so the two never disagree.

Loading

Each animation is self-contained — the keyframes travel inside the SVG.

Keypress

Primary. The cap actuates and the cursor blinks off on the release.

Flip

The cap holds still. The caret flips through edge-on and the cursor blinks out on the turn.

hjkl

Long waits. The caret walks left, down, up, right — one press per direction.

Prompt

Inline. Sits at the end of a line of CLI output at x-height.

In a line of output

The mark's stem, alone, scanning inside a single character cell. No colour, no cap, no second glyph — it inherits the terminal's foreground and never disturbs the column grid.

One colour

Masked, so it inherits currentColor — good for terminal output, stamps, embroidery, favicons.

Line cut

One stroke weight, no filled masses, transparent ground. Ink is currentColor, so a single file sits on light or dark.

The lip stays: plate inset 12 at the sides and top, 24 at the bottom, so the silhouette matches the solid cut exactly. Strokes and the gaps between them are both 6 units — the mark is built on one number.

Small sizes

Below 24px the standard cap fills in. The compact cut thickens the legend and widens the plate — swap at 24px.

Using it

Clear space

Keep the width of the cursor stem — 9 units, or 7.5% of the mark's width — clear on all four sides. In dense UI, the cap's own lip reads as breathing room, so nothing extra is needed.

Don't

Add gradients, bevels or drop shadows — the two flat tones are the depth. Recolour the plate. Outline the cap. Close the gap between cursor and caret. Rotate the cap: it is always face-on.
